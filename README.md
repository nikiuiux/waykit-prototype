# WayKit · прототип

Рабочий прототип сайта аренды авто WayKit по макетам из Фигмы (файл «WK Проектирование»).

## Экраны

| Экран | Файл | Статус |
|---|---|---|
| Первый экран с поиском: город, даты, параметры | `dist/waykit-search.html` | готов |

## Как посмотреть

Открыть `dist/waykit-search.html` в браузере. Файл самодостаточный: шрифты, фото и иконки встроены, интернет не нужен.

## Как править

- `src/template.html` — вёрстка, стили и логика. Правки вносятся здесь.
- `src/assets/` — шрифты PT Root UI VF и Onest SemiBold, фото баннера.
- `src/build.py` — собирает `dist/waykit-search.html` из шаблона и ассетов.

Сборка: `python3 src/build.py`

Токены в CSS названы как переменные в Фигме: `--oat-soft-900`, `--sage-500`, `--red-error`.

## Поведение поиска

- Город: при наведении показывается в поле, клик выбирает и открывает календарь.
- Даты: реальная сегодняшняя дата, прошлые недоступны. Первый клик начало, второй конец, между ними превью при наведении.
- Параметры: пассажиры 1–7, цена 1 000–30 000 ₽ с шагом 500, коробка передач. Поле заполнено, только если параметры изменены.
- «Найти»: если не заполнено ни одно поле, «Город» и «Период аренды» подсвечиваются red/error.
- Esc и клик вне блока закрывают выпадашку. Если выпадашка не помещается в окно, страница докручивается.
- Ниже 1024 px поля встают столбиком.
